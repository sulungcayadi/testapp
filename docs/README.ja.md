# Copilot Agent Hub と T1 研修: ユーザーガイド

[English](../README.md) · **日本語** · [简体中文](README.zh-CN.md) · [ไทย](README.th.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

このアプリは、社員が **1 つの目的を持つ 1 つの Microsoft 365 Copilot エージェント** を作り、テストし、安全に使えるように学ぶためのローカル Web アプリです。研修のあとは、組織における Copilot エージェントの唯一の入口になります。エージェント登録とガバナンスレビュー、アイデアボード、ライセンス申請、コーチのネットワーク、プロンプトライブラリ、導入状況の分析、先進企業とのベンチマークを備えています。

Python が入っている PC であれば動きます。追加のインストールもインターネット接続も不要で、データはすべて 1 つの SQLite ファイルに保存されます。アプリ全体を **英語、日本語、簡体字中国語、タイ語、インドネシア語、ベトナム語** で利用できます。

## はじめかた

1. <https://www.python.org/downloads/> から **Python 3.8 以降** をインストールします。Windows ではセットアップ中に *Add Python to PATH* にチェックを入れてください。
2. このフォルダーをダウンロードまたはクローンします。
3. アプリを起動します。
   - **Windows:** `start_windows.bat` をダブルクリック
   - **macOS / Linux:** `./start_mac_linux.sh` を実行
   - **任意のターミナルから:** `python app.py`
4. ブラウザーで <http://127.0.0.1:8000> が開きます。初回は管理者アカウントを作成します。
5. 受講者はサインイン画面で **アカウントを作成** を選び、社員 ID で登録します。

終了するには、ターミナルで `Ctrl+C` を押すか、ウィンドウを閉じます。

## 言語の切り替え

すべてのページ (サインイン画面を含む) の上部にある **言語** メニューから表示言語を選べます。選んだ言語は記憶されます。

画面、レッスン、クイズの問題と解説、ラボの手順、テンプレート、用語集、ベンチマーク表、通知、修了証まで翻訳されています。次の 2 つは意図的に英語のままです。

- *New agent*、*Configure*、*Try it*、*Can chat*、*Settings > Personalization* などの **Microsoft の画面ラベル**。受講者が Microsoft 365 Copilot で実際に目にする表示と同じにするためです。
- **Microsoft Learn の参照ページのタイトル**。講師が元のページを探しやすくするためです。

テンプレートページでは、翻訳されたテンプレートごとに **英語の原文** も表示できます。エージェントの指示を英語で書くよう定めている組織もあるためです。管理者が入力したテキスト (組織独自の問題や利用ガイドライン) は入力されたとおりに表示されます。

## 受講者向けガイド

1. **ホーム** で進捗と次にやることを確認します。
2. **マイコース** でコア研修 (10 モジュール、29 レッスン、約 150 分) を進めます。各レッスンを読んだら *レッスンを完了にする* を押します。時間がない場合は、レッスン 1.3 にある 60 分の要点ルートを使えます。
3. 各モジュールの最後に **小テスト** があります。解答後すぐに正解と解説が表示され、何度でも受け直せます。
4. **マイエージェントチャーター** で、作るエージェントの目的、やること・やらないこと、知識ソースを計画します。チャーターからエージェントの指示の下書きが作られ、そのままハブに登録できます。
5. **ラボ** ページを開いたまま Microsoft 365 Copilot で 12 のステップを実施し、「完了の目安」を満たしたらチェックを入れます。ステップ 1 から 10 が必須です。
6. **最終テスト** は 58 問の問題バンクから 15 問が出題され、重要な 3 問は必ず含まれます。合格ラインは初期設定で 80% です。
7. すべてのレッスン、ラボのステップ 1 から 10、最終テストが終わると **修了証** が表示されます。印刷または PDF として保存できます。

**スキルチェック** (約 2 分) に答えると、おすすめのモジュールが表示されます。**ラーニングパス** ではビルダーレベル 1 から 3 と、それぞれで解放される共有範囲を確認できます。管理職向けの **リーダートラック** と、コーチ向けの **コーチトラック** は任意です。

**ツールキット** には、コピーボタン付きテンプレート、印刷用クイックリファレンス、用語集、Microsoft の参照資料、講師ガイド、ポリシーとヘルプがあります。

## エージェントハブの使いかた

| 機能 | 使いかた |
|---|---|
| **エージェント登録** | 自分以外と共有するエージェントは、目的、オーナー、ティア、知識ソース、データの機密度、共有範囲、ベースライン付きの KPI を 1 つ、テスト結果、レビュー日とともに登録します。作る前に、承認済みカタログで再利用できるエージェントがないか検索してください。 |
| **ガバナンスレビュー** | チームや組織全体と共有するエージェント、または機密データを使うエージェントは、コーチのレビューキューに送られ、8 項目のチェックリストで確認されます。ティア 3 と 4 (データに対して操作する、または自律的に動く) は CoE がレビューします。申請には T1 の修了証が必要です。 |
| **90 日の価値レビュー** | 承認されたエージェントにはレビュー日が設定されます。オーナーは KPI の結果を記録し、測定できる価値のないエージェントは廃止します。 |
| **アイデアボード** | Copilot で手伝えそうな業務を投稿し、投票やコメントをします。アイデアから作られたエージェントはそのアイデアにひも付けられます。 |
| **ライセンス申請** | チームとして、ユースケースと見込み削減時間を添えて Microsoft 365 Copilot のライセンスを申請します。CoE が期待効果の高い順に、ウェーブ単位で承認します。 |
| **コミュニティ** | コーチの名簿と相談時間、イベント (プロンプトソン、成果発表会、ライブ研修)、評価付きのプロンプトライブラリがあります。 |
| **CoE に質問** | ポリシー、データ、ライセンス、インシデントに関する質問を送ります。利用ガイドラインとデータの取り扱いルールも同じページにあります。 |
| **削減時間の記録** | ハブのホームで、毎週どれだけ時間を削減できたかを記録します。 |
| **通知** | レビューの結果、ライセンスの決定、アイデアへのコメント、CoE からの回答が届きます。 |

## コーチ向けガイド

- 目安は社員 60 人あたりコーチ 1 人です (社員 10,000 人なら約 170 人)。
- プロフィールに相談時間を書くと、コミュニティの名簿に表示されます。
- **レビュー待ち一覧** で、チームや組織と共有されるエージェントを確認します。目的、ティア、知識ソース、データの機密度、テスト結果を読み、オーナーからチャットリンクをもらって、自分でも 3 つのテストを実行してください。
- チェックリストのすべての項目を満たした場合のみ承認できます。満たしていなければ、変更点を説明して *修正を依頼* を選びます。自分のエージェントはレビューできません。

## 管理者 (CoE) 向けガイド

- **概要**: 読み込み済みの社員数、修了・受講中・未着手の人数、最終スコアとフィードバックの平均、部門別の修了率、モジュールごとの離脱状況を確認します。
- **受講者**: 検索・絞り込み、詳細の編集、パスワードのリセット、コーチへの任命ができます。
- **社員の取り込み**: CSV (`associate_id, name, email, department, location`) をアップロードします。再インポートすると情報が更新され、進捗は保持されます。
- **CSV 出力**: 進捗レポート全体と、全言語の問題バンク (正解付き) を出力できます。
- **問題バンク**: 正答率の低い順に表示されます。問題の無効化や組織独自の問題の追加ができます。
- **設定**: 組織名、合格ライン、組織の利用ガイドライン (空欄なら翻訳済みのひな形が表示されます)。
- **インサイト** と **ベンチマーク**: 研修、エージェント、アイデア、ライセンス、削減時間を 1 つのダッシュボードで確認し、社員数に合わせた目標と比較します。

## 10,000 人への展開

- **社員の事前登録**: 人事から出力したリストを CSV テンプレートに入れて取り込むか、`python app.py import-users associates.csv` を実行します。
- **全員で 1 つのデータベースを使う場合**: イントラネットからアクセスできるマシンで `python app.py --host 0.0.0.0 --port 8000` を実行します。HTTP で動作するため、信頼できる社内ネットワークでのみ公開するか、組織の HTTPS リバースプロキシの後ろに置いてください。事前に IT 部門に相談してください。
- **バックアップ**: データはすべて `data/training.db` にあります。アプリを止めてからコピーしてください。

## コマンド一覧

```text
python app.py                          アプリを起動 (ブラウザーが開きます)
python app.py --port 8080 --no-browser 別のポートを使い、ブラウザーを開かない
python app.py --host 0.0.0.0           ネットワークで待ち受ける (上の展開の注意を参照)
python app.py create-admin             管理者を追加、または既存アカウントを昇格
python app.py import-users FILE.csv    CSV から社員を取り込み・更新
python app.py export FILE.csv          進捗レポートを CSV に出力
python app.py reseed                   training/content.py の編集後にコース内容を再読み込み
python app.py demo-data 500            試用のため架空の DEMO 受講者を 500 人追加
python app.py i18n-extract --check     各言語の未翻訳の数を表示
python app.py i18n-extract --missing ja  日本語に未翻訳の英語テキストを一覧表示
```

`demo-data` はテスト用のデータベースでのみ使ってください。

## コース内容と翻訳の更新

1. `training/content.py` と `training/blocks.py` の英語テキストを編集します。
2. `python app.py reseed` を実行します。受講者の進捗とテスト履歴は保持されます。
3. `python app.py i18n-extract --check` で、変更された箇所のうち各言語で未翻訳のものを確認し、`training/locales/` に翻訳を追加します。翻訳が追加されるまでは英語が表示されます。
4. アプリを再起動します。

**研修を実施する前に**、講師は次を確認してください。
- 参照資料ページの各 Microsoft Learn ページを開き、手順とラベルが自社のテナントと一致しているか確認する。Microsoft は Copilot の画面を頻繁に更新します。
- モジュール 4 に、自社で確認したスクリーンショットを追加する。アプリには Microsoft のスクリーンショットは含まれていません。
- 事例とベンチマークの出典を、発表の前に確認し直す。
- 管理 → 設定で、ひな形の利用ガイドラインを承認済みのものに置き換える。

## 範囲と制限

- このアプリは Microsoft 365 に接続しません。テナント内のエージェントを確認したり、受講者が実際にエージェントを作ったかを検証したりはできません。ラボと登録は自己申告で、コーチはレビュー時にチャットリンクで確認します。
- ベンチマークの数値は、アプリ内に日付付きで示した企業・ベンダー・報道の公開情報に基づくもので、独立した監査は受けていません。
- シングルサインオン (Microsoft Entra ID) はありません。アカウントはアプリ内で管理されます。
- 翻訳はこのプロジェクトのために作成したものです。ほかの研修資料と同様に、展開前に各国のネイティブの講師に確認してもらってください。
