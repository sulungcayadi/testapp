# Copilot Agent Hub 与 T1 培训：用户指南

[English](../README.md) · [日本語](README.ja.md) · **简体中文** · [ไทย](README.th.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

这是一个本地网页应用，帮助员工学会构建**一个只有一个用途的 Microsoft 365 Copilot 智能体**，并进行测试和安全使用。培训之后，它会成为组织内 Copilot 智能体的唯一入口：包括智能体登记与治理审核、创意墙、许可证申请、教练网络、提示词库、采用情况分析，以及与领先企业的对标。

任何装有 Python 的电脑都能运行。无需额外安装，也不需要联网；所有数据保存在一个 SQLite 文件中。整个应用支持**英语、日语、简体中文、泰语、印尼语和越南语**。

## 快速开始

1. 从 <https://www.python.org/downloads/> 安装 **Python 3.8 或更高版本**。在 Windows 上安装时请勾选 *Add Python to PATH*。
2. 下载或克隆本文件夹。
3. 启动应用：
   - **Windows：** 双击 `start_windows.bat`
   - **macOS / Linux：** 运行 `./start_mac_linux.sh`
   - **或在任意终端中：** `python app.py`
4. 浏览器会打开 <http://127.0.0.1:8000>。首次启动时请创建管理员账户。
5. 学员在登录页选择**创建账户**，用员工编号注册。

要停止应用，在终端窗口按 `Ctrl+C`（或直接关闭窗口）。

## 切换语言

每个页面（包括登录页）顶部都有**语言**菜单，选择后会被记住。

界面、课程、测验题目和解析、实操步骤、模板、术语表、对标表格、通知和结业证书都已翻译。以下两类内容有意保留英文：

- **Microsoft 界面标签**，例如 *New agent*、*Configure*、*Try it*、*Can chat* 和 *Settings > Personalization*。学员在 Microsoft 365 Copilot 中看到的就是这些标签，因此课程原样使用。
- **Microsoft Learn 参考页面的标题**，方便讲师找到原始页面。

在模板页面，每个已翻译的模板还可以查看**英文原文**，因为有些组织要求用英文编写智能体说明。管理员自行输入的内容（组织自定义题目、可接受使用准则）按原样显示。

## 学员指南

1. 在**首页**查看进度和下一步。
2. 在**我的课程**中学习核心课程（10 个模块、29 节课，约 150 分钟）。读完每节课后点击*标记课程为已完成*。时间紧张时，可以按照第 1.3 课中的 60 分钟精简路线学习。
3. 每个模块结束后有一个**小测验**，提交后立即显示正确答案和解析，可以反复作答。
4. 在**我的智能体章程**中规划智能体的用途、做什么和不做什么，以及知识来源。章程会自动生成智能体说明草稿，并可直接登记到中心。
5. 打开**实验**页面，同时在 Microsoft 365 Copilot 中完成 12 个步骤，满足"完成标准"后勾选。第 1 到第 10 步为必做。
6. **结业考试**从 58 道题的题库中抽取 15 题，并始终包含 3 道关键知识检查题。默认及格线为 80%。
7. 完成全部课程、实验第 1 到第 10 步和结业考试后，即可获得**结业证书**，可以打印或另存为 PDF。

完成约 2 分钟的**技能自评**后，会看到推荐的模块。在**学习路径**中可以查看构建者等级 1 到 3，以及每一级解锁的共享范围。面向管理者的**领导者路径**和面向教练的**教练路径**为选修。

**工具包**中有带复制按钮的模板、可打印的速查卡、术语表、Microsoft 参考资料、讲师指南，以及政策与帮助页面。

## 智能体中心的使用方法

| 功能 | 使用方法 |
|---|---|
| **智能体登记** | 凡是分享给自己以外的人的智能体，都要登记用途、负责人、等级、知识来源、数据敏感度、共享范围、一个带基线的 KPI、测试结果和审核日期。构建之前，请先在已批准目录中搜索是否已有可复用的智能体。 |
| **治理审核** | 要分享给团队或整个组织的智能体，或使用机密数据的智能体，会进入教练的评审队列，按 8 项清单检查。等级 3 和 4（对数据执行操作或自主运行）由 CoE 审核。提交前必须持有 T1 结业证书。 |
| **90 天价值审核** | 获批的智能体会设定审核日期。负责人记录 KPI 结果，没有可衡量价值的智能体将被停用。 |
| **创意墙** | 发布 Copilot 可以协助的工作，投票并评论。根据创意构建的智能体会关联回该创意。 |
| **许可证申请** | 团队提交 Microsoft 365 Copilot 席位申请，并附上使用场景和预计节省的小时数。CoE 按预期价值从高到低分批审批。 |
| **社区** | 教练名录和答疑时间、活动（提示词马拉松、成果展示、直播培训），以及带评分的提示词库。 |
| **咨询 CoE** | 提交关于政策、数据、许可证和事件的问题。同一页面还有可接受使用准则和数据规则。 |
| **记录节省时间** | 在中心首页记录每周节省的小时数。 |
| **通知** | 接收审核结果、许可证决定、创意评论和 CoE 的回复。 |

## 教练指南

- 建议每 60 名员工配备 1 名教练（10,000 名员工约 170 名）。
- 在个人资料中填写答疑时间，就会显示在社区名录中。
- 在**评审队列**中检查要分享给团队或组织的智能体。阅读用途、等级、知识来源、数据敏感度和测试结果，向负责人索取聊天链接，并亲自运行三项测试。
- 只有清单上每一项都满足时才能批准。否则请选择*要求修改*并说明需要改什么。不能审核自己的智能体。

## 管理员（CoE）指南

- **概览**：已导入员工数，已结业、学习中和未开始的人数，结业考试和反馈的平均分，各部门结业率，以及模块漏斗。
- **学员**：搜索和筛选，编辑信息，重置密码，或任命为教练。
- **导入员工**：上传 CSV（`associate_id, name, email, department, location`）。重复导入会更新信息并保留进度。
- **CSV 导出**：完整进度报告，以及任意或全部语言的题库（含答案）。
- **题库**：按正确率从低到高排列。可以停用题目或添加组织自定义题目。
- **设置**：组织名称、及格线，以及组织自己的可接受使用准则（留空则显示已翻译的模板准则）。
- **洞察**与**对标分析**：在一个仪表板中查看培训、智能体、创意、许可证和节省时间，并与按员工人数换算的目标对比。

## 面向 10,000 名员工推广

- **预先导入员工**：把人力资源导出的名单放进 CSV 模板导入，或运行 `python app.py import-users associates.csv`。
- **所有人共用一个数据库**：在内网可访问的机器上运行 `python app.py --host 0.0.0.0 --port 8000`。应用使用 HTTP，请只在可信的内部网络中开放，或放在组织的 HTTPS 反向代理之后。请事先与 IT 部门确认。
- **备份**：所有数据都在 `data/training.db` 中。请在停止应用后复制该文件。

## 命令参考

```text
python app.py                          启动应用（会打开浏览器）
python app.py --port 8080 --no-browser 使用其他端口，且不打开浏览器
python app.py --host 0.0.0.0           在网络上监听（见上方推广说明）
python app.py create-admin             添加管理员，或提升现有账户
python app.py import-users FILE.csv    从 CSV 导入或更新员工
python app.py export FILE.csv          将进度报告导出为 CSV
python app.py reseed                   修改 training/content.py 后重新加载课程内容
python app.py demo-data 500            添加 500 名虚构的 DEMO 学员用于试用
python app.py i18n-extract --check     显示各语言缺少的翻译数量
python app.py i18n-extract --missing zh-CN  列出尚未翻译成简体中文的英文文本
```

`demo-data` 只能在测试数据库中使用。

## 更新课程内容和翻译

1. 编辑 `training/content.py` 和 `training/blocks.py` 中的英文文本。
2. 运行 `python app.py reseed`。学员进度和测验记录会保留。
3. 运行 `python app.py i18n-extract --check`，查看改动内容在各语言中还有哪些未翻译，并在 `training/locales/` 中补充翻译。补充之前会显示英文。
4. 重启应用。

**开课之前**，讲师应当：
- 打开参考资料页面中的每个 Microsoft Learn 页面，确认步骤和标签与本组织租户一致。Microsoft 经常更新 Copilot 界面。
- 为第 4 模块添加本组织核实过的截图。应用中不包含 Microsoft 截图。
- 在展示前重新核对案例和对标数据的来源。
- 在"管理 → 设置"中，将模板准则替换为已批准的准则。

## 范围与限制

- 本应用不连接 Microsoft 365，无法查看租户中的智能体，也无法核实学员是否真的构建了智能体。实验和登记均为自行申报，教练在审核时通过聊天链接进行核实。
- 对标数据来自应用中注明日期的企业、厂商和媒体公开信息，未经独立审计。
- 不支持单点登录（Microsoft Entra ID），账户在应用内管理。
- 译文为本项目编写。与其他培训材料一样，推广前请由各国母语讲师审阅。
