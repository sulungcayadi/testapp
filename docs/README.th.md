# Copilot Agent Hub และหลักสูตร T1: คู่มือผู้ใช้

[English](../README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · **ไทย** · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

แอปนี้เป็นเว็บแอปที่ทำงานบนเครื่อง ใช้สอนพนักงานให้สร้าง**เอเจนต์ Microsoft 365 Copilot หนึ่งตัวที่มีจุดประสงค์เดียว** ทดสอบ และใช้งานอย่างปลอดภัย หลังจบการอบรม แอปจะเป็นประตูหลักเพียงแห่งเดียวสำหรับเอเจนต์ Copilot ในองค์กร ได้แก่ ทะเบียนเอเจนต์พร้อมการรีวิวด้านการกำกับดูแล บอร์ดไอเดีย คำขอไลเซนส์ เครือข่ายโค้ช คลังพรอมต์ ข้อมูลเชิงลึกด้านการใช้งาน และการเปรียบเทียบกับบริษัทชั้นนำ

ใช้ได้กับคอมพิวเตอร์ทุกเครื่องที่มี Python ไม่ต้องติดตั้งอะไรเพิ่มและไม่ต้องต่ออินเทอร์เน็ต ข้อมูลทั้งหมดเก็บไว้ในไฟล์ SQLite ไฟล์เดียว ทั้งแอปมีให้เลือกเป็น**ภาษาอังกฤษ ญี่ปุ่น จีนตัวย่อ ไทย อินโดนีเซีย และเวียดนาม**

## เริ่มต้นใช้งาน

1. ติดตั้ง **Python 3.8 ขึ้นไป** จาก <https://www.python.org/downloads/> บน Windows ให้ติ๊ก *Add Python to PATH* ระหว่างติดตั้ง
2. ดาวน์โหลดหรือโคลนโฟลเดอร์นี้
3. เปิดแอป:
   - **Windows:** ดับเบิลคลิก `start_windows.bat`
   - **macOS / Linux:** รัน `./start_mac_linux.sh`
   - **หรือจากเทอร์มินัลใดก็ได้:** `python app.py`
4. เบราว์เซอร์จะเปิด <http://127.0.0.1:8000> ในการเปิดครั้งแรก ให้สร้างบัญชีผู้ดูแลระบบ
5. ผู้เรียนเลือก**สร้างบัญชีของคุณ**ในหน้าลงชื่อเข้าใช้ แล้วลงทะเบียนด้วยรหัสพนักงาน

หากต้องการหยุดแอป ให้กด `Ctrl+C` ในหน้าต่างเทอร์มินัล (หรือปิดหน้าต่าง)

## การเปลี่ยนภาษา

ทุกหน้า (รวมถึงหน้าลงชื่อเข้าใช้) มีเมนู**ภาษา**อยู่ด้านบน ระบบจะจำภาษาที่เลือกไว้

หน้าจอ บทเรียน คำถามและคำอธิบายในแบบทดสอบ ขั้นตอนแล็บ เทมเพลต อภิธานศัพท์ ตารางเปรียบเทียบ การแจ้งเตือน และใบประกาศนียบัตร ได้รับการแปลทั้งหมด มีสองอย่างที่ตั้งใจคงไว้เป็นภาษาอังกฤษ:

- **ป้ายบนหน้าจอของ Microsoft** เช่น *New agent*, *Configure*, *Try it*, *Can chat* และ *Settings > Personalization* เพราะผู้เรียนจะเห็นป้ายเหล่านี้ใน Microsoft 365 Copilot หลักสูตรจึงใช้ตามนั้นทุกตัวอักษร
- **ชื่อหน้าแหล่งอ้างอิงของ Microsoft Learn** เพื่อให้ผู้สอนหาหน้าต้นฉบับได้

ในหน้าเทมเพลต เทมเพลตที่แปลแล้วแต่ละชุดจะมี**ต้นฉบับภาษาอังกฤษ**ให้ดูด้วย เพราะบางองค์กรกำหนดให้เขียนคำสั่งเอเจนต์เป็นภาษาอังกฤษ ข้อความที่ผู้ดูแลระบบพิมพ์เอง (คำถามเฉพาะขององค์กร แนวทางการใช้งาน) จะแสดงตามที่พิมพ์

## คู่มือสำหรับผู้เรียน

1. ที่**หน้าแรก** ดูความคืบหน้าและสิ่งที่ควรทำต่อ
2. ใน**หลักสูตรของฉัน** เรียนหลักสูตรหลัก (10 โมดูล 29 บทเรียน ประมาณ 150 นาที) อ่านแต่ละบทเรียนแล้วกด*ทำเครื่องหมายว่าเรียนบทนี้จบแล้ว* หากมีเวลาน้อย ให้ใช้เส้นทางสาระสำคัญ 60 นาทีที่อธิบายไว้ในบทเรียน 1.3
3. ท้ายแต่ละโมดูลมี**แบบทดสอบ**สั้น ๆ หลังส่งคำตอบจะเห็นคำตอบที่ถูกและคำอธิบายทันที และทำซ้ำได้ไม่จำกัด
4. ใน**กฎบัตรเอเจนต์ของฉัน** วางแผนจุดประสงค์ สิ่งที่ทำและไม่ทำ และแหล่งความรู้ของเอเจนต์ ระบบจะร่างคำสั่งเอเจนต์จากกฎบัตรให้ และลงทะเบียนในศูนย์ได้ทันที
5. เปิดหน้า**แล็บ**ไว้ระหว่างทำ 12 ขั้นตอนใน Microsoft 365 Copilot และติ๊กเมื่อเงื่อนไข "เสร็จเมื่อ" เป็นจริง ขั้นตอน 1 ถึง 10 เป็นข้อบังคับ
6. **แบบทดสอบท้ายหลักสูตร**สุ่ม 15 ข้อจากคลังข้อสอบ 58 ข้อ โดยมีคำถามสำคัญ 3 ข้อเสมอ เกณฑ์ผ่านเริ่มต้นคือ 80%
7. เมื่อเรียนครบทุกบทเรียน ทำแล็บขั้นตอน 1 ถึง 10 และผ่านแบบทดสอบท้ายหลักสูตรแล้ว จะได้รับ**ใบประกาศนียบัตร** ซึ่งพิมพ์หรือบันทึกเป็น PDF ได้

ทำ**ประเมินทักษะ** (ประมาณ 2 นาที) แล้วจะเห็นโมดูลที่แนะนำ ใน**เส้นทางการเรียนรู้** ดูระดับผู้สร้าง 1 ถึง 3 และขอบเขตการแชร์ที่ปลดล็อกในแต่ละระดับ **เส้นทางผู้นำ**สำหรับผู้บริหาร และ**เส้นทางโค้ช**สำหรับโค้ช เป็นวิชาเลือก

**ชุดเครื่องมือ**มีเทมเพลตพร้อมปุ่มคัดลอก บัตรอ้างอิงด่วนสำหรับพิมพ์ อภิธานศัพท์ แหล่งอ้างอิงของ Microsoft คู่มือผู้สอน และหน้านโยบายและความช่วยเหลือ

## วิธีใช้ศูนย์เอเจนต์

| ฟีเจอร์ | วิธีใช้ |
|---|---|
| **ทะเบียนเอเจนต์** | เอเจนต์ที่แชร์ให้ผู้อื่นต้องลงทะเบียนพร้อมจุดประสงค์ เจ้าของ ระดับ แหล่งความรู้ ความอ่อนไหวของข้อมูล ขอบเขตการแชร์ KPI หนึ่งตัวพร้อมค่าตั้งต้น ผลการทดสอบ และวันที่รีวิว ก่อนสร้าง ให้ค้นหาในแคตตาล็อกที่อนุมัติแล้วว่ามีเอเจนต์ที่ใช้ซ้ำได้หรือไม่ |
| **การรีวิวด้านการกำกับดูแล** | เอเจนต์ที่จะแชร์กับทีมหรือทั้งองค์กร หรือใช้ข้อมูลลับ จะเข้าสู่คิวรอรีวิวของโค้ชและตรวจตามรายการ 8 ข้อ ระดับ 3 และ 4 (ลงมือกับข้อมูลหรือทำงานอัตโนมัติ) รีวิวโดย CoE ผู้ส่งต้องมีใบประกาศนียบัตร T1 |
| **การรีวิวคุณค่า 90 วัน** | เอเจนต์ที่อนุมัติแล้วจะมีวันที่รีวิว เจ้าของบันทึกผล KPI และเลิกใช้เอเจนต์ที่ไม่มีคุณค่าที่วัดได้ |
| **บอร์ดไอเดีย** | โพสต์งานที่ Copilot ช่วยได้ โหวต และแสดงความคิดเห็น เอเจนต์ที่สร้างจากไอเดียจะเชื่อมโยงกลับไปที่ไอเดียนั้น |
| **คำขอไลเซนส์** | ทีมขอที่นั่ง Microsoft 365 Copilot พร้อมกรณีการใช้งานและชั่วโมงที่คาดว่าจะประหยัดได้ CoE อนุมัติเป็นระลอก โดยเรียงจากคุณค่าที่คาดหวังสูงสุด |
| **ชุมชน** | รายชื่อโค้ชและช่วงเวลาให้คำปรึกษา กิจกรรม (พรอมต์ทอน โชว์ผลงาน การอบรมสด) และคลังพรอมต์ที่มีการให้คะแนน |
| **ถาม CoE** | ส่งคำถามเรื่องนโยบาย ข้อมูล ไลเซนส์ และเหตุการณ์ หน้าเดียวกันมีแนวทางการใช้งานและกฎด้านข้อมูล |
| **บันทึกชั่วโมงที่ประหยัดได้** | บันทึกชั่วโมงที่ประหยัดได้ทุกสัปดาห์ที่หน้าแรกของศูนย์ |
| **การแจ้งเตือน** | รับผลการรีวิว การตัดสินเรื่องไลเซนส์ ความคิดเห็นในไอเดีย และคำตอบจาก CoE |

## คู่มือสำหรับโค้ช

- แนะนำให้มีโค้ช 1 คนต่อพนักงาน 60 คน (ประมาณ 170 คนสำหรับพนักงาน 10,000 คน)
- ระบุช่วงเวลาให้คำปรึกษาในโปรไฟล์ แล้วชื่อคุณจะแสดงในรายชื่อของชุมชน
- ใน**คิวรอรีวิว** ตรวจเอเจนต์ที่จะแชร์กับทีมหรือองค์กร อ่านจุดประสงค์ ระดับ แหล่งความรู้ ความอ่อนไหวของข้อมูล และผลการทดสอบ ขอลิงก์แชทจากเจ้าของ แล้วรันการทดสอบทั้งสามแบบด้วยตัวเอง
- อนุมัติได้เมื่อทุกข้อในรายการตรวจสอบเป็นจริงเท่านั้น มิฉะนั้นให้เลือก*ขอให้แก้ไข*และอธิบายสิ่งที่ต้องเปลี่ยน คุณรีวิวเอเจนต์ของตัวเองไม่ได้

## คู่มือสำหรับผู้ดูแลระบบ (CoE)

- **ภาพรวม**: จำนวนพนักงานที่โหลดแล้ว จำนวนผู้ได้รับใบประกาศ กำลังเรียน และยังไม่เริ่ม คะแนนเฉลี่ยของแบบทดสอบท้ายหลักสูตรและความคิดเห็น อัตราการได้รับใบประกาศแยกตามแผนก และกราฟโมดูลที่ผู้เรียนหลุดออก
- **ผู้เรียน**: ค้นหาและกรอง แก้ไขรายละเอียด รีเซ็ตรหัสผ่าน หรือ*ตั้งให้บุคคลนี้เป็นโค้ช*
- **นำเข้าข้อมูลพนักงาน**: อัปโหลด CSV (`associate_id, name, email, department, location`) การนำเข้าซ้ำจะอัปเดตข้อมูลและเก็บความคืบหน้าไว้
- **ส่งออก CSV**: รายงานความคืบหน้าทั้งหมด และคลังข้อสอบพร้อมคำตอบในภาษาใดภาษาหนึ่งหรือทุกภาษา
- **คลังข้อสอบ**: เรียงจากอัตราตอบถูกต่ำสุด ปิดการใช้คำถามหรือเพิ่มคำถามเฉพาะขององค์กรได้
- **การตั้งค่า**: ชื่อองค์กร เกณฑ์ผ่าน และแนวทางการใช้งานขององค์กร (หากเว้นว่างจะแสดงแนวทางเริ่มต้นที่แปลแล้ว)
- **ข้อมูลเชิงลึก**และ**การเปรียบเทียบ (Benchmark)**: ดูการอบรม เอเจนต์ ไอเดีย ไลเซนส์ และชั่วโมงที่ประหยัดได้ในแดชบอร์ดเดียว และเทียบกับเป้าหมายที่ปรับตามจำนวนพนักงาน

## การขยายผลสู่พนักงาน 10,000 คน

- **โหลดรายชื่อพนักงานล่วงหน้า**: ใส่รายชื่อที่ส่งออกจากฝ่ายบุคคลลงในเทมเพลต CSV แล้วนำเข้า หรือรัน `python app.py import-users associates.csv`
- **ใช้ฐานข้อมูลเดียวร่วมกัน**: รัน `python app.py --host 0.0.0.0 --port 8000` บนเครื่องที่เข้าถึงได้จากอินทราเน็ต แอปใช้ HTTP จึงควรเปิดเฉพาะในเครือข่ายภายในที่เชื่อถือได้ หรือวางไว้หลัง HTTPS reverse proxy ขององค์กร ปรึกษาฝ่ายไอทีก่อน
- **การสำรองข้อมูล**: ข้อมูลทั้งหมดอยู่ใน `data/training.db` ให้คัดลอกไฟล์นี้ขณะที่แอปหยุดทำงาน

## คำสั่งที่ใช้ได้

```text
python app.py                          เปิดแอป (เบราว์เซอร์จะเปิดขึ้น)
python app.py --port 8080 --no-browser ใช้พอร์ตอื่น และไม่เปิดเบราว์เซอร์
python app.py --host 0.0.0.0           รับการเชื่อมต่อจากเครือข่าย (ดูหมายเหตุการขยายผลด้านบน)
python app.py create-admin             เพิ่มผู้ดูแลระบบ หรือยกระดับบัญชีที่มีอยู่
python app.py import-users FILE.csv    นำเข้าหรืออัปเดตพนักงานจาก CSV
python app.py export FILE.csv          ส่งออกรายงานความคืบหน้าเป็น CSV
python app.py reseed                   โหลดเนื้อหาหลักสูตรใหม่หลังแก้ไข training/content.py
python app.py demo-data 500            เพิ่มผู้เรียนสมมติ DEMO 500 คนเพื่อทดลองใช้
python app.py i18n-extract --check     แสดงจำนวนข้อความที่ยังไม่ได้แปลในแต่ละภาษา
python app.py i18n-extract --missing th  แสดงข้อความภาษาอังกฤษที่ยังไม่ได้แปลเป็นภาษาไทย
```

ใช้ `demo-data` กับฐานข้อมูลทดสอบเท่านั้น

## การอัปเดตเนื้อหาและคำแปล

1. แก้ไขข้อความภาษาอังกฤษใน `training/content.py` และ `training/blocks.py`
2. รัน `python app.py reseed` ความคืบหน้าและประวัติแบบทดสอบของผู้เรียนจะยังอยู่
3. รัน `python app.py i18n-extract --check` เพื่อดูว่าข้อความที่เปลี่ยนยังไม่ได้แปลในภาษาใด แล้วเพิ่มคำแปลใน `training/locales/` ระหว่างที่ยังไม่มีคำแปล ระบบจะแสดงภาษาอังกฤษ
4. เปิดแอปใหม่

**ก่อนเริ่มสอน** ผู้สอนควร:
- เปิดหน้า Microsoft Learn แต่ละหน้าในหน้าแหล่งอ้างอิง และยืนยันว่าขั้นตอนและป้ายตรงกับองค์กรของคุณ Microsoft อัปเดตหน้าจอ Copilot บ่อย
- เพิ่มภาพหน้าจอที่ตรวจสอบแล้วขององค์กรคุณสำหรับโมดูล 4 แอปไม่มีภาพหน้าจอของ Microsoft
- ตรวจสอบแหล่งที่มาของกรณีศึกษาและข้อมูลเปรียบเทียบอีกครั้งก่อนนำเสนอ
- แทนที่แนวทางการใช้งานเริ่มต้นด้วยแนวทางที่ได้รับอนุมัติ ที่ผู้ดูแล → การตั้งค่า

## ขอบเขตและข้อจำกัด

- แอปนี้ไม่เชื่อมต่อกับ Microsoft 365 จึงมองไม่เห็นเอเจนต์ในองค์กรและตรวจสอบไม่ได้ว่าผู้เรียนสร้างเอเจนต์จริงหรือไม่ แล็บและทะเบียนเป็นการรายงานด้วยตนเอง และโค้ชตรวจสอบผ่านลิงก์แชทระหว่างการรีวิว
- ตัวเลขเปรียบเทียบมาจากข้อมูลสาธารณะของบริษัท ผู้ขาย และสื่อ ซึ่งระบุวันที่ไว้ในแอป และไม่ได้ผ่านการตรวจสอบอิสระ
- ไม่มีการลงชื่อเข้าใช้ครั้งเดียว (Microsoft Entra ID) บัญชีจัดการภายในแอป
- คำแปลจัดทำขึ้นสำหรับโครงการนี้ ควรให้ผู้สอนที่เป็นเจ้าของภาษาในแต่ละประเทศตรวจทานก่อนใช้งานจริง เช่นเดียวกับสื่อการอบรมอื่น ๆ
